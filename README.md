# QWCC DFW Demo

Live demo of the Definable Features of Work dashboard.

## Deploy to Vercel (get a shareable link in 3 minutes)

### Step 1 — Push to GitHub
1. Go to [github.com/new](https://github.com/new)
2. Create a new **private** repo called `qwcc-demo`
3. Upload this folder's contents (drag and drop the unzipped folder)

### Step 2 — Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and sign up / log in (free)
2. Click **Add New → Project**
3. Import the `qwcc-demo` repo from GitHub
4. Click **Deploy** — no environment variables needed

Done. Vercel gives you a URL like `qwcc-demo.vercel.app` that works on any device.

---

## Run locally instead

```bash
npm install
npm run dev
```
